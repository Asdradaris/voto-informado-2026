# VOTO INFORMADO 2026

Plataforma ciudadana de investigación electoral para las elecciones generales de Perú 2026.

Investiga, evalúa y compara candidatos presidenciales con datos verificables de fuentes públicas.

## Stack

- React 18 + TypeScript + Vite 7
- Tailwind CSS v4
- Zustand (state management con persistencia)
- Recharts (visualizaciones)
- Framer Motion (animaciones)
- React Router v6 (navegación con lazy loading)

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Configurado para Vercel (`vercel.json`) y Netlify (`netlify.toml`).

## Disclaimer

Esta es una herramienta informativa ciudadana independiente. No está afiliada a ningún partido político, candidato u organismo electoral. Los datos provienen de fuentes públicas verificables.
